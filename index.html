01 — THE PLATFORM

More than a chat window.

AxiomUI connects conversational AI with the mechanisms needed to act: context, tools, scheduled work and operational controls.

PRODUCT OVERVIEW
◈

Conversational agents

Agents work with conversation history, prepared context and tool-call loops to handle requests.

⌁

Model router

Classifies prompts and routes them to the first usable configured model for that task class.

⌘

Tools & integrations

Extend agents with tools, MCP servers, reusable skills and messaging channels.

◷

Persistent jobs

Schedule recurring work with persisted execution, retries and crash recovery.

▤

Memory & context

Maintain conversations across sessions and prepare relevant context for agent runs.

⌬

Multimodal capabilities

Voice, image and video features are available through configured providers and optional sidecars.

⛨

Guarded actions

Dangerous actions can require approval, with optional OS sandboxing for supported processes.

◎

Operational visibility

Opt-in OpenTelemetry traces and metrics help inspect model calls and system activity.

04 — ENGINEERING

Java first. Deliberately lean.

AxiomUI is built on a customized Play Framework 1.x foundation, using focused libraries and JVM capabilities rather than a heavy application framework.
